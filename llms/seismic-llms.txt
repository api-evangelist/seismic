# Seismic

> Seismic is an enterprise sales-enablement platform: content management, LiveDocs document
> generation, learning and coaching, buyer engagement (Digital Sales Rooms, LiveSend), and the
> analytics over all of it. The public API surface is the Seismic integration API at
> https://api.seismic.com/integration/v2, a SCIM 2.0 identity surface at
> https://api.seismic.com/scim/v2, a webhook/event surface, and a first-party remote MCP server.

Generated by API Evangelist from the artifacts in this repository on 2026-09-17. Seismic does not
publish an llms.txt of its own — https://developer.seismic.com/llms.txt returns 404 (probed
2026-09-17). This file is API Evangelist's generation, not Seismic's.

Access model: enterprise. There is no public pricing page and no self-serve sign-up; tokens come
from a provisioned tenant. Authentication is OAuth 2.0 / OpenID Connect against
https://auth.seismic.com. Scope alone is not authorization — a tenant administrator grants the
underlying permission separately, so a correctly-scoped token can still take a 403.

## Agent surfaces

- [MCP server](mcp/seismic-mcp.yml): remote, Streamable HTTP, https://mcp.seismic.com/v1 (or
  https://mcp.seismic.com/v1/tenants/<tenant_name>). 20 published tools covering Digital Sales
  Rooms, meetings, LiveSend and generative search. Requires a Seismic JWT user access token with
  the seismic.mcp scope, PLUS tenant-administrator permission to invoke tools. Anonymous
  tools/list returns 401 with an RFC 9728 challenge.
- [MCP-to-REST crosswalk](mcp/seismic-tool-crosswalk.yml): the MCP tools and the OpenAPI operations
  are almost entirely disjoint — the MCP server is an engagement product, not a wrapper over the
  integration API. No destructive REST operation is exposed as a tool.
- [Agent skills](skills/_index.yml): packaged operating instructions grounded in real operationIds.
- [Agentic access contracts](agentic-access/seismic-agentic-access.yml)
- No A2A agent card is published (probed 2026-09-17 on every host).

## Runtime semantics

- [Conventions](conventions/seismic-conventions.yml): pagination (offset/limit), async 202 + job
  polling, and two facts an agent must know before writing — there is NO idempotency mechanism of
  any kind on this API, and no reversal WINDOW is published for any write.
- [Rate limits](rate-limits/seismic-rate-limits.yml): tenant-scoped, 60-second rolling window,
  tiers 10 / 30 / 60 / 600 calls per minute. Headers are X-Seismic-Remaining-Calls and
  X-Seismic-Total-Calls; there is no Retry-After — the wait is a sentence in the 429 body.
- [Errors](errors/seismic-problem-types.yml): plain JSON envelope {statusCode, message, clientId,
  tenant}. Not RFC 9457. No named error codes.
- [Lifecycle](lifecycle/seismic-lifecycle.yml): per-route versioning, deprecation window of 1 to 12
  months, no Sunset/Deprecation headers.
- [Webhooks](asyncapi/seismic-webhooks.yml): 56 documented events, HMAC-SHA256 signing via
  x-seismic-signature, 26 delivery attempts over ~24 hours. No AsyncAPI document is published.
- [Sandbox](sandbox/seismic-sandbox.yml): https://api-sandbox.seismic.com. No public test
  credentials or fixtures.
